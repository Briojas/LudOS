# LudOS v0.7.1 Changes

## Critical Fixes for Tesla P4 GPU Support

### Gamescope Display
- **Fixed**: Changed `--prefer-vk-device` from `/dev/dri/card1` to PCI ID format `10de:1bb3`
  - This ensures Gamescope selects the Tesla P4 GPU instead of llvmpipe software renderer
  - File: `build_files/ludos-gamescope-display`

- **Fixed**: Removed VK_ICD_FILENAMES environment restriction
  - Allows Vulkan to auto-detect available ICDs instead of forcing nvidia_icd.json only
  - File: `build_files/ludos-gamescope-display.service`

### Sunshine Streaming
- **Added**: NVIDIA CUDA device access for NVENC hardware encoding
  - Added `/dev/nvidia0` and `/dev/nvidiactl` to DeviceAllow
  - File: `build_files/ludos-setup.sh` (lines 110-111)

- **Fixed**: Cleaned up Sunshine configuration with only valid options
  - Removed invalid encoder options that caused warnings
  - Set `nvenc_preset = llhq` for Tesla P4 compatibility
  - File: `build_files/ludos-setup.sh` (lines 46-69)

- **Added**: GPU persistence mode enablement
  - Runs `nvidia-smi -pm 1` during setup (required for NVENC in systemd services)
  - File: `build_files/ludos-setup.sh` (lines 172-179)

### Known Behavior
- Sunshine logs will show "Multiple reference frames are not supported" warnings during encoder testing
  - **This is normal and non-fatal**
  - Sunshine automatically finds compatible encoder settings for Tesla P4
  - NVENC encoders (h264_nvenc, hevc_nvenc) are successfully detected and functional
